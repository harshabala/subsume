# Page audit, 2026-11-18 (after Workstream 3 and search speed improvements)

Follow-up report to `docs/audit/2026-11-16-page-audit.md` (North Star plan, workstreams 2, 3 and 4).
Produced by `npm run audit:pages` (`scripts/audit_pages.py`, raw numbers in `docs/audit/results/results.json`).

## Summary of Changes

1. **Year Handling & Designed Gaps**: "Year unknown" is correctly treated as a designed gap rather than a defect (`scripts/audit_pages.py`). Pre-1800 years save and show correctly.
2. **Medium-Aware Cards & Creator Lines**:
   - `HardcoverSpineCard` (Library) now shows the creator line (`By <author>` for books, `Directed by <director>` for films, `Created by <creator>` for series).
   - `SanctuaryMediaCard` (Search, Home, Recommendations) renders creator line for each medium.
3. **Detail Modal Medium Details**:
   - Film/Series director or creator rendered.
   - Size/length display: runtime (`runtimeMinutes min`) for screen titles and page count (`pageCount pages`) for books.
4. **Home Page Hero**:
   - Prioritizes the owner's own inscribed title from the library instead of feed defaults.
   - Says `Written by <author>` for books and `Directed by <director>` for films.
   - Recently Inscribed cards render the release/publication year.
5. **Stats Page Honest Computations**:
   - Calculates hours on screen and book pages read strictly from stored values.
   - Honest missing data state: explicitly displays `(unknown for N titles)` rather than misleadingly claiming `0 hrs on screen`.
6. **Speed & Offline Search**:
   - Eliminated artificial 7.6s retry backoff in `tmdb.ts` when offline / receiving 503 HTTP responses.
   - Book search includes stored works first, ensuring saved books render with complete stored metadata.
   - Search time dropped from **~7,600 ms** to **105 ms** (median).
   - Enforced per-page time budgets in `scripts/audit_pages.py` (search <= 2000 ms, other pages <= 800-1000 ms).

## Completeness Assessment vs 95% Plan Bar

- **Reaching >= 95% bar**:
  - Library: Series (100%)
  - Library-Detail: Series (100%)
  - Search: Series (100%)
  - Home: Film (100%), Series (100%)
  - Recommendations: Series (100%), Book (100%)
- **Why other categories remain below 95% (without invent data)**:
  - **Film runtime**: The audit runs in an offline/keyless environment. TMDb film runtime cannot be fetched without an API key; film records in seed/fixtures legitimately have `size:not-stored` (17/18). Per plan rules ("Never invent metadata. A field with no source stays empty and is shown as a designed gap"), runtime remains empty and is honestly shown as a gap.
  - **Open Library Book descriptions/genres/covers**: Free Open Library records for obscure historical or regional titles (e.g. Kokila, Chemmeen) often lack work-level overviews or edition page counts in the public API dumps (`not-stored`), and 1 synthetic fixture deliberately lacks a cover. Every field that *is* stored is now 100% rendered with zero `stored-not-shown` omissions on Library, Home, Recommendations, and Detail.
