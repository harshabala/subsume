## What Subsume is for

Subsume is a Manifest V3 Chrome extension that works as a private movie, TV and book journal. While you browse, a content script notices film, series and book title pages (JSON-LD, ISBNs, domain adapters) and adds quiet overlays so you can save a title without leaving the page. Saving opens an emotion-first capture canvas ("What stayed with you?"), and everything lands in a local IndexedDB archive that you can browse, filter by medium and intent, export, or back up to Google Drive by hand. Optional extras: TMDb/OMDb/Google Books metadata, people/creator follows, release alerts, and LLM recommendations using your own API keys. The user is one person who watches and reads a lot and wants a private, offline-first record of what affected them, not a social tracker. The core loop must work with zero API keys and no account.

### Bugs found in the real browser

1. **"Reflect" tab reuse never works.** `openCaptureCanvasTab` looks for an existing journal tab with `chrome.tabs.query({})` and matches on `tab.url`. Without the `tabs` permission Chrome returns `url: undefined` for every tab, including the extension's own pages (confirmed: all four open tabs came back with `null` URLs). So each Reflect click opens another tab, and the unit tests pass only because they mock URLs in.
2. **Zero-key path logs errors.** With no TMDb key, the service worker logs `console.error("Failed to load genre map: TMDB API key not configured")` again and again. Not having a key is a normal state, not an error, and it fills the extension's error page.
3. **Broken poster icons.** When a poster URL fails (offline, 404, or a blocked CDN), the popup and cards show the browser's broken-image glyph.

## Plan

### (a) Locally verifiable — do now, highest impact first

1. **Fix Reflect tab reuse.** Find the journal tab with `chrome.runtime.getContexts` (no extra permission; Chrome 116+), fall back to `tabs.query`, and raise `minimum_chrome_version` to 116. Write the test first, then verify in the real browser that a second Reflect reuses the tab.
2. **Drop the unused `activeTab` permission.** Add a test that pins the manifest permission set to what the code uses, and update the `store/` permission docs and checklist.
3. **Quiet the zero-key genre map.** Skip the TMDb genre fetch when there's no key, and log at debug level instead of `console.error`. Test first.
4. **Poster fallback.** Add a shared `PosterImage` component that swaps to a typographic placeholder on `error`, and use it in the popup and the main cards. Test first, then confirm in the browser with images blocked.
5. **Test the untested core handlers.** Cover `handlers/titles.ts` (content-script-reachable poster/page resolution and details) and `handlers/people.ts`.
6. **Lint as a gate.** Fix all 99 ESLint warnings, change `npm run lint` to run ESLint with `--max-warnings 0`, add it to `npm run ci` and the CI workflow, and fix the content-bundle `import.meta` warning.
7. **Honest real-browser smoke test.** Replace the Brave-only cold-install script with one that uses Playwright's bundled Chromium (or `CHROME_PATH`), stubs network, and asserts real outcomes (first save, every page renders, tab reuse, no uncaught errors). Document it as an optional local check.
8. **Docs truth pass.** Fix the inaccurate README claims, remove the tracked `Icon\r`, label the stale September plan as superseded, and note duplicate instruction docs in a short `docs/README.md` index.
